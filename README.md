# vtui_graphics — небольшая библиотека TUI (ядро)

Кратко: vtui_graphics — лёгкая библиотека для построения текстового пользовательского интерфейса
(TUI). В данный момент разрабатывается и стабилизируется ядро рендеринга и утилиты для работы с
UTF‑8 и ANSI‑последовательностями.

Статус
-----
- Активная разработка: модуль core (отрисовка, буферы, вывод) и утилиты UTF‑8 находятся в прогрессе.
- Код ориентирован на Windows (MSVC) с использованием CMake + Ninja; части платформо‑зависимого
  слоя находятся в src/core/platform.

Быстрый старт (сборка)
---------------------
Требования:
- CMake >= 3.10
- Ninja
- Microsoft Visual Studio (MSVC) — рекомендовано под Windows

Сборка из корня репозитория (пример для PowerShell):

```powershell
mkdir build
cmake -S . -B build -G "Ninja" -DCMAKE_BUILD_TYPE=Release
c:
cmake --build build --config Release
```

Или откройте проект/решение в Visual Studio и соберите конфигурацию.

Структура репозитория
---------------------
- include/ — публичные заголовки (vtui API)
- src/ — реализация (core, util, platform)
- example/ — небольшой пример использования
- CMakeLists.txt — конфигурация сборки
